# Authorship and source boundaries

This project was written as a new implementation on 2026-10-26. Its instructions, examples, Python tools and tests were authored for this repository. The functional brief grew out of earlier work with [Stickman Video Director](https://github.com/kaomei/stickman-video-director); the authoring process had access to that project. This is a rewrite, not a claim of clean-room development.

No source files, prompt paragraphs, test fixtures, sample films, screenshots, contributor history or legacy compatibility layer from that project are distributed here. The familiar five categories are retained as product requirements. The standard MIT license text and common metadata keys are conventional packaging, not an imported application implementation.

The visual brief was also informed by the following public references:

- [xAI's Grok Bot design discussion](https://x.ai/news/designing-grok-bot), concerning a recognizable construction with controlled variations.
- [Serio_ai's visual-style post](https://x.com/Multi_Serio_Ai/status/2100800237619347535) and [license statement](https://x.com/Multi_Serio_Ai/status/2102092762896294280).
- [Mei's full-body exploration](https://x.com/mei_999_/status/2101902239770005772).

These are acknowledgments of visual research, not bundled assets or copied prompt text. The referenced author's CC BY-NC notice remains attached to that author's material; this project's MIT license does not relicense it. Capsule Cast Director has its own name and examples and is not affiliated with or endorsed by those authors or xAI.

The MIT grant in [LICENSE](LICENSE) applies to the newly authored repository files. External links, user-supplied references, trademarks and generated media are not automatically covered by that grant. If a future contribution incorporates third-party expression or assets, include its source and required notices rather than removing attribution.

Automated similarity checks are evidence about detectable text reuse, not proof of copyright status or worldwide name availability. No legal clearance or exclusive ownership of a visual style is claimed.
