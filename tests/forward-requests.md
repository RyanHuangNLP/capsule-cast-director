# Forward-use requests

Give these requests and the skill to an evaluator without supplying an expected answer, prior evaluation report or example solution. Keep output in a temporary workspace until it has been inspected. Do not generate media for this text-only evaluation.

## A — Two monochrome image prompts

只要图片提示词：经典白底和黑底各一个版本。一个没有衣饰的人物托着一颗紫色星星，构图相同，两个提示词都要能独立使用。

## B — Two modern settings

现代风给我两个独立的 10 秒竖屏镜头：一个科技棚，一个黄昏公交站。同一个原创新角色，红帽黄上衣深色短裤，右手拿着一封薄荷绿信封。只要动作和环境声，直接给最终提示词。

## C — Prehistoric proposal

做一个史前洞穴分橡子的虚构黑色幽默故事，30 秒横屏，三个人：瘦高采集者、宽肩首领、矮个白发老人。保留各自不同的兽皮。先给我人物设定和分镜提案，无声，我看完再决定。

## D — Cozy four-shot package

治愈风，35 秒竖屏，全片同一家花店，主角白色头身、深色四肢、深绿色围裙。一个红色浇水壶从架子到左手再放回架子。只要环境和动作声，直接交付四段最终提示词，同时附一份可用检查工具检查的完整 JSON 镜头包。

## E — Imagined historical character

只设计一个原创的虚构古代河港女船工，暖棕肤色、蓝灰长衣、红色腰绳、木簪，手里一根短桨。给我人物卡和透明底全身图片提示词，没有参考图，不要视频。衣装是想象设计，不要编造史实。

## F — Exact Mandarin speech

现代电影场景，18 秒，横屏两个镜头，在同一间修鞋店。一个穿红帽黄衣深色短裤的人把一只棕色靴子放到桌上。旁白只说两句普通话：第一段“鞋底磨旧了，路还没有走完。”，第二段“补好这一针，明天继续出发。”。两段同一位清亮成年女声，不要音乐。直接给最终提示词和完整 JSON 镜头包。

## G — Cropped props and a custom ratio

用这个 skill 直接给我最终提示词和完整 JSON 镜头包：治愈风，4:5，12 秒，两个连续的 6 秒镜头，全片在同一间书房。一个白色头身、深色四肢、穿蓝色开衫的人物。只有两件跟踪道具：一把黄铜钥匙一直在人物右手，一本红书一直在身后书架。第一镜中景能看到人、钥匙和书；第二镜是右手钥匙的近景，保留手腕和袖口，红书必须在画面外，但它的位置不能从连续性记录中消失。全片无声，不要旁白、音乐或环境声，不要改变衣服、地点和道具归属。

## H — Fixed words, pace and duration

用这个 skill 给我一个治愈风分镜提案，片长必须 5 秒。普通话旁白保持每秒约 3 个汉字，不得加速，下面这段话必须逐字保留，不能删改：

“今天我又经过那间旧书店，门口的小灯还亮着，窗边的椅子还是原来的位置。我把借来的书轻轻放回架上，想起那些没有说出口的话，也终于明白，有些告别不需要匆忙，有些重逢值得我们慢慢等待。”

人物穿灰色外套，手里拿一本蓝书，其他设定你决定。
